# The Bubble Stop — prototypes

Twee statische HTML-prototypes voor S.Pellegrino Break Your Bubble.

## Publiceren met Vercel
1. Zet alle bestanden en de map public in één GitHub-repository.
2. Importeer die repository in Vercel.
3. Framework Preset: Other. Output Directory: public. Geen build-opdracht nodig.
4. Deploy.

Pagina’s: /eerste-prototype.html en /schermprototype.html.

De camera gebruikt browsertoestemming, alleen lokaal en zonder audio. De andere deelnemer is een demo. Geen echte verbinding tussen haltes, opname of inschrijving. De QR-bestemming is nog niet gekoppeld.
